# Anniversaire de Maman ✨

Une petite expérience web en HTML/CSS/JavaScript pour souhaiter un joyeux anniversaire à maman.

## Inclus
- Ambiance gris anthracite, argent et doré
- Enveloppe animée
- Message d'anniversaire
- Lettre avec effet machine à écrire
- Pluie de paillettes dorées
- Musique de fond : `You Say.mp3`
- Bouton musique et bouton rejouer
- Compatible GitHub Pages

## Personnaliser la lettre
Modifie la constante `LETTER` dans `script.js`.

## GitHub Pages
Publier la branche `main` depuis `/ (root)`.

> Le fichier audio est inclus à titre personnel. Vérifie les droits/licences applicables avant de publier publiquement une musique commerciale.
